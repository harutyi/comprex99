# デモ共通テンプレート

このフォルダは公開しない作業用テンプレートです。新しい業種デモは、この `_template` をコピーして作ります。

## 新しい業種デモを作る手順

1. `_template` を `demos/<slug>/` にコピーする。
2. `base.css` は変更しない。全業種共通のレイアウト専用にする。
3. 業種ごとの配色や装飾だけを `theme-*.css` に書く。
4. `index.html` の `<!-- REPLACE:キー -->...<!-- /REPLACE -->` で囲まれた箇所だけを差し替える。
5. 写真を `img/` に入れ、`img/CREDITS.txt` に取得元と利用条件を残す。

## デモ品質の共通ルール

- ファーストビューは業種らしい写真を主役にする。イラストや薄い背景だけで作らない。
- 店名、地域、予約導線、業種の空気感を最初の画面で伝える。
- 下層はカードを並べるだけにしない。初回の不安、料金、流れ、アクセスの順で読む人を案内する。
- デモは「きれい」より「営業先が自分の店に置き換えて想像できる」ことを優先する。
- 共通CSSは構造だけにして、業種の印象はテーマCSSと画像で出す。

## 通話中に既存店向けサンプルを作る手順

1. `seitai-tsukiakari` など近い業種のデモをコピーする。
2. 差し替えるのは `店名`、`地域`、`電話番号`、`住所` の4種類だけ。
3. 写真やメニューは急いで差し替えない。電話では「写真とメニューは御院のものに全部差し替わります」と説明する。
4. URLを送るときは「サンプル」と呼ぶ。
5. 断られたら即削除する。

## やってはいけないこと

- `noindex, nofollow` を外さない。
- 実店舗の写真を無断で使わない。GoogleマップやInstagramからの転用は、本人に見せる目的以外で公開状態に置かない。
- 断られたサンプルを残さない。
- 他店に転用しない。
- 「仮公開」と呼ばない。必ず「サンプル」と呼ぶ。

## 整体院・接骨院の注意点

接骨院は国家資格や保険適用の有無で表現できる範囲が変わります。整体院は民間資格扱いの場合があります。実店舗向けに差し替える前に、必ず整体院なのか接骨院なのか、国家資格や保険適用を出せるのかを確認してください。

効果の断定、最上級表現、裏付けのない資格表記、ビフォーアフター写真は使いません。本文では「お悩みに向き合います」「目的とした施術です」のように断定しない表現を使います。
